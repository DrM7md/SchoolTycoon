# الأداء واستهلاك الموارد

في قياس محلي لبناء Release، نفذت النواة 10,000 حملة أو 300,000 يوم في نحو **108 مللي ثانية** وخصصت نحو **15,768 بايت لكل حملة** على خيط القياس. هذا قياس للمحاكاة فقط. تخصيص الذاكرة التراكمي يختلف عن ذاكرة التطبيق المقيمة. تتغير النتائج مع الجهاز ونسخة التشغيل.

```powershell
dotnet run --project tests/SchoolDirectorTycoon.Tests -c Release --no-build -- --benchmark
```

- عند توقف الوقت يُوقف مؤقت المحاكاة. للحرم المرئي مؤقت مستقل للحركة بمعدل يقارب 15 تحديثًا في الثانية، ويتوقف عند إخفاء العنصر أو تعطيل الحركة في Windows. تُحفظ رسومات الأرض والمباني لتجنب إعادة توليدها لكل إطار. التحديث مرتبط بالقرارات ومرور الأيام، والسجل محدود بثلاثين يومًا.
- حساب اليوم يتعامل مع مجموعات وأعداد ثابتة الحجم. نسخ سجل التقارير عند إضافة تقرير يتناسب مع طول السجل المحدود.
- الحفظ التلقائي متزامن مع واجهة Windows. قِس زمن الكتابة واستجابة النافذة عند سرعة ×16 قبل تمديد الحملة أو زيادة بياناتها. إذا أصبح الحفظ ملحوظًا، انقل لقطات الحالة الثابتة إلى طابور كاتب واحد يحافظ على ترتيب الحفظ.
- في الجولة التالية قِس زمن بدء التشغيل، والذاكرة المقيمة، واستخدام المعالج في الوقوف و×16، وزمن الحفظ على جهاز متوسط وآخر منخفض المواصفات. سجّل الوسيط وP95 لأزمنة الاستجابة إلى جانب الجهاز والإعدادات.
- عند الانتقال إلى أفراد أو حملة أطول، قِس أثر كل تغيير وحدّث حدود الاحتفاظ بالتقارير واستهلاك الذاكرة قبل إضافة تخزين أوسع.
