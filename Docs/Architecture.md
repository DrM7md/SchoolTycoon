# البنية

| الجزء | المسؤولية |
| --- | --- |
| `Core/CampusLayout.cs` | شبكة الحرم وقواعد مواقع البناء وتوزيع مرافق الحملات السابقة |
| `Desktop/CampusMap.cs` | العرض الإيزومتري والكاميرا واختيار مواقع البناء |
| `Core/SchoolState.cs` | نموذج الحالة وسجل اليوم والنتيجة، باستخدام سجلات وقائمة تقارير غير قابلة للتعديل المباشر |
| `Core/Simulation.cs` | أوامر البناء والتوظيف والرسوم والحدث وإنهاء اليوم. كل أمر يستقبل حالة ويعيد حالة |
| `Core/SaveStore.cs` | تسلسل JSON والإصدار والتحقق والاستبدال المحلي. المسار يُمرر من المستدعي |
| `Desktop/MainWindow.xaml` | تخطيط لوحة الإدارة والاستجابة لاتجاه القراءة |
| `Desktop/MainWindow.xaml.cs` | تحويل تفاعل اللاعب إلى أوامر، وتوقيت الأيام، وتحديث اللوحة، والحفظ |
| `Desktop/LanguagePreference.cs` | قراءة وكتابة تفضيل اللغة محليًا بصورة مستقلة عن الحملة |
| `Desktop/InterfaceText.cs` | ترجمات عناصر الواجهة الثابتة. النصوص المركّبة تُبنى في طبقة العرض |
| `tests` | اختبار محاكاة مستقل عن Windows واختبار واجهة Windows منفصل |

## دورة القرار

زر أو مؤقت ← أمر في المحاكاة ← حالة جديدة ← عرض الحالة. عند إنهاء اليوم بنجاح تُكتب خانة الحفظ التلقائي. يُحسب تنبيه السعة وتغطية المعلمين من الحالة الحالية عند عرضها. رفض الأمر يبقي الحالة السابقة ويعرض رسالة في لغة اللاعب. تحفظ حالة المولّد العشوائي مع الحملة، حتى يتطابق تسلسل الأحداث عند إعادة نفس القرارات بعد التحميل.

تعمل أوامر الواجهة على خيط WPF بالتتابع. يحدد آخر استبدال ناجح للخانة محتواها عند تشغيل أكثر من نسخة من التطبيق. راجع [الحفظ](SaveSystem.md) و[الأداء](Performance.md) قبل تعديل هذا المسار.

## عميل Unity

اعتُمد Unity 6 عميلًا قادمًا للعرض والإدخال، مع بقاء `Core` مصدر قواعد اللعب. تُبنى النواة لهدفين `net10.0;netstandard2.1` بلغة C# 9. يُطوَّر العميل بالإنجليزية أولًا مع جداول نصوص قابلة للتعريب. التفاصيل والمراحل في [الانتقال إلى Unity](UnityMigration.md). إعادة تصميم البيانات قبل الأعوام المتتالية في [نموذج البيانات 3](DataModelV3.md)، والاعتمادات في [الأطراف الثالثة](ThirdParty.md).

## مسار الجوال

يستهدف `Core` الإطارين `net10.0` و`netstandard2.1` (C# 9) دون مرجع إلى WPF. يمكن لواجهة جوال مستقبلية استخدام الحالة والأوامر ومخزن الحفظ بعد توفير مسار داخل مساحة التطبيق. ستحتاج النسخة المحمولة إلى واجهة لمس جديدة، وإدارة تعليق التطبيق، واختبار التخزين وإدارة دورة الحياة على الجهاز المستهدف. يُتوقع أن يكون عميل Unity هو مسار الجوال لاحقًا، بعد تحديد المنصات والمتطلبات.
