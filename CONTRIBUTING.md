# Contributing

Thank you for helping. Start with [AGENTS.md](AGENTS.md) and [Docs/Development.md](Docs/Development.md). The ground rules are in the [README](README.md#ground-rules-for-contributions).

## How to contribute

1. Open an issue first for anything bigger than a small fix, so we can agree on the direction.
2. Keep each pull request focused on one change.
3. Run the Core tests and, for Unity changes, the EditMode tests. Update `Docs/Changelog.md`.
4. Add every visible string in both English and Arabic.
